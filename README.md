# miniOS

Главные особенности самописных ОС:

Отсутствие стандартов:в них нет привычных библиотек языка C или стандартных API. Разработчику приходится самостоятельно создавать драйверы, управление памятью и планировщик процессов.

Минимализм: часто такие системы умещаются на одной дискете и загружаются за пару секунд.

Обучение: написание даже простейшего ядра дает глубокое понимание того, как процессор общается с оперативной памятью, диском и периферией.Известные примеры.Некоторые самописные проекты перерастают в полноценные системы или становятся культовыми в сообществе:

KolibriOS: невероятно быстрая и компактная система на ассемблере, которая полностью помещается на дискету.

TempleOS: легендарная система, написанная одним человеком (Терри Дэвисом) с нуля, включая собственный компилятор.

ArozOS: необычный open-source проект, представляющий собой веб-ориентированную десктопную ОС для облачных хранилищ.
